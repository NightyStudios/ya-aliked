# ALIKE-N/L: HPatches

Финальный код для расчёта метрик и выгрузки точек. Модель и веса взяты из
[Shiaoming/ALIKE](https://github.com/Shiaoming/ALIKE), исходная лицензия сохранена.
Это ALIKE, не ALIKED.

## Установка

Python 3.12 и NVIDIA GPU с поддержкой CUDA. Проверено с PyTorch 2.7.1/cu128.

```powershell
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install torch==2.7.1 torchvision==0.22.1 --index-url https://download.pytorch.org/whl/cu128
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
```

## Запуск

Распакуйте полные последовательности HPatches: в каждой серии должны быть
`1.ppm`–`6.ppm` и `H_1_2`–`H_1_6`.

```powershell
.\.venv\Scripts\python.exe evaluate.py --dataset "C:\path\to\hpatches-sequences-release"
```

По умолчанию запускаются N и L. Для одной модели добавьте `--models alike-n`
или `--models alike-l`. Результаты сохраняются в `results/`:

- `alike-n.json`, `alike-l.json`: метрики по каждой паре и средние.
- `keypoints.csv`: `model,seq,type,img,idx,x,y,score`; индекс точки начинается с 0,
  координаты относятся к исходному изображению.

## Настройки и метрики

Отбор по `scores_th=0.2`, `top_k=0`, максимум 5000 точек; subpixel включён.
Один масштаб, без изменения разрешения. Сопоставление — взаимные ближайшие
соседи по скалярному произведению нормированных дескрипторов, на GPU.

Исключаются восемь ненадёжных серий авторского протокола и серии, в которых
хотя бы одно изображение имеет короткую сторону >1200 или длинную >1600.
Ориентация не учитывается. Датасет не изменяется. В нашем наборе остаётся
106 серий, 636 изображений, 530 пар (1→2, …, 1→6).

Пороги в массивах JSON: 1, 2, 3 пикселя; значения — доли от 0 до 1.

- `mma`: доля мэтчей с ошибкой проекции по истинной гомографии ≤ порога.
- `mha_corner_fraction`: доля четырёх углов с ошибкой ≤ порога; эта MHA
  использовалась в нашей последней сравнительной таблице.
- `mha_author_code`: доля пар, для которых средняя ошибка четырёх углов
  ≤ порога; соответствует формуле опубликованного кода авторов.
- `ms`: удвоенное число правильных совместно видимых мэтчей, делённое на
  сумму совместно видимых точек обоих изображений.

Гомография оценивается OpenCV RANSAC с его стандартным порогом 3 пикселя.
Метрики усредняются по парам. MMA авторской статьи воспроизведена до её
округления; точное совпадение опубликованной MHA не подтверждено.

Датасет, результаты, окружение и диагностические версии кода в этот пакет
не включены. Папки `data/`, `results/` и `.venv/` исключены через `.gitignore`.
